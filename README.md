One line of awkward small talk that one robot says to another while they ride an elevator together: a courtesy loop with no exit condition, and a battery that is not going to outlast yours. The program writes the line to `entry.txt` in the output directory.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
